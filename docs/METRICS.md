# Métricas e decisão

O Autoonn prioriza sinais de negócio em vez de views isoladas.

- CTR = cliques / views
- Conversão = vendas / cliques
- Comissão = retorno atribuído
- Retenção = qualidade do criativo

Regra inicial: abaixo de 300 views, continuar teste; com venda ou CTR >2%, criar nova variação; com amostra suficiente e nenhum sinal, parar. Esses limites são parâmetros iniciais e devem ser recalibrados com dados reais.
