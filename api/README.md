# Autoonn API

Backend mínimo para manter credenciais fora do navegador.

Rodar: `npm run api`.

Variáveis: `TIKTOK_CLIENT_KEY`, `TIKTOK_CLIENT_SECRET`, `TIKTOK_REDIRECT_URI`, `TIKTOK_SCOPES`, `APP_ORIGIN`.

O endpoint de publicação permanece deliberadamente bloqueado até a autorização oficial ser concluída.
